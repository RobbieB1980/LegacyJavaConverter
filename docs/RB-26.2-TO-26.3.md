# RB 26.2 → 26.3 Converter Preview

The 26.2-to-26.3 target is a separate GUI and script package because 26.3
changes client rendering/windowing, pack formats, worldgen JSON, codecs, and
several Java APIs. The existing legacy converter remains pinned to NeoForge 26.2.

The preview GUI is built from:

`src/RB.RB262To263Converter/RB.RB262To263Converter.csproj`

The deterministic engine is:

`targets/rb-26.2-to-26.3/Convert-RB262To263.ps1`

The engine refuses non-26.2 inputs, requires a distinct output directory, and
requires an explicit NeoForge 26.3 version until an official stable pin is
available. It writes `conversion-manifest.json` and `MIGRATION_EVIDENCE.md`.

Automated passes currently cover exact version markers, pack metadata, the safe
`surface_rule` to `material_rule` rename, and unambiguous aquifer field moves.
Renderer/client Java changes, ambiguous worldgen, dependencies, build success,
runtime launch, and gameplay behavior remain separate gates.

Run the contract test:

```powershell
& .\tests\Test-RB262To263Target.ps1
```
